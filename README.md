 结果：
1.写了一版cpp的贪吃蛇，需使用EasyX

2.原有代码基础上改动：
（1） 基础得分：每吃 1 个食物 +10 分
（2）**速度随分数提升**：分数越高，刷新间隔越短，游戏变快[未指示功能]
（3） 游戏结束时打印最终总分
（4） 修复随机数，增加头文件 `#include <cstdlib>`
（5） 增加注释，代码逻辑不变，只扩展积分相关逻辑

3.HTML+JS 贪吃蛇（带积分、难度随分数提升，浏览器直接打开）

4.新增加功能：
（1） **最高分记录**，刷新页面、关闭浏览器不会丢失（浏览器本地存储 localStorage）
（2） 页面同时显示「当前分数」和「历史最高分」
（3） 游戏结束时，如果本次分数超过最高分，自动更新最高分
（4） 原有游戏逻辑不变：方向键控制、分数越高速度越快

5.# 完整代码：带 AI 自动游玩（Codex 风格 BFS 寻路 + 安全预判）、积分榜、手动 / AI 切换

新功能：
✅ **AI 自动游玩**：BFS 寻路找食物，吃完前预判能否回到蛇尾，防止把自己封死（不是简单贪心直冲，稳定性强很多）
✅ 【开启 AI】【重置游戏】按钮，一键切换人机模式
✅ 本地存储最高分积分榜
✅ 保留原有手动方向键游玩
✅ AI 决策每帧自动修改蛇移动方向
